WhatsApp Translator for Mac — v0.3.2 / build 302
WhatsApp 翻译助手：中文 / English / Español

安装（中文）
1. 适用 Apple Silicon Mac、macOS 26 或更新版本、原生 WhatsApp 客户端。
2. 将 WhatsApp Bilingual.app 拖到 Applications，从“应用程序”打开。
3. 选择界面语言、阅读与输入语言、回复目标语言。这三项可以分别设置。
4. 在系统设置中为 WhatsApp Bilingual 开启辅助功能；若没有条目，点 + 选择应用程序里的助手。
5. 按设置页准备并测试所选语言包，首次下载需连接 Apple。可勾选登录启动。
6. 点击“开始使用 WhatsApp”，打开聊天，在 WhatsApp 原输入框写回复。停笔 5 秒后转换，检查后手动发送。

日常使用
- 阅读与输入语言：收到的消息译成此语言；也用于识别你写草稿的语言。
- 顶部 中文 / EN / ES：回复目标。与输入语言相同时不转换。
- 撤销：恢复此条原始草稿；未暂停时停笔 5 秒会重新翻译。暂停助手可留出措辞时间。
- 翻译面板自动贴边、可收起；切到其他应用时隐藏。菜单栏可重新打开。
- 原文对照用于核对；实时内容只覆盖已加载消息，更早记录可导入 WhatsApp 文本导出文件。
- 菜单“检查更新”：匿名访问 GitHub，发现新版后可点击“下载并更新”。助手会校验安装包并重启。

更新与卸载
更新前退出助手，将新版替换到原 Applications 路径。设置和自动启动保留。
签名变化后可能需在系统权限中移除旧条目，再添加当前助手。
卸载前在设置中取消登录启动，退出助手，再删除应用和对应权限条目。

要求与限制
本软件尚未获得 Apple Developer ID 签名与公证。若被 macOS 或公司策略阻止，请联系 IT 核验或等待签名版，不要关闭安全保护。
翻译使用 Apple 本机引擎，无需 API 密钥、Codex、Xcode 或按次付费。聊天与译文仅在运行内存中，不上传至翻译服务器。
已验证中英西六个翻译方向返回结果，以及英文↔西语原输入框转换和撤销等操作；不能保证机器翻译准确性。
原生实测 WhatsApp 2.26.46.15 中文界面。英／西语 WhatsApp 界面解析仍待实际验收。
不支持 Intel Mac、Windows、网页端、手机及其他聊天软件，不翻译图片、GIF、语音或附件内部内容。
语言包下载连接 Apple；更新检查和下载连接 GitHub。金额、日期、姓名及重要约定请核对原文。

English quick start
1. Requires Apple Silicon, macOS 26+, and native WhatsApp for Mac.
2. Drag WhatsApp Bilingual.app into Applications and launch it.
3. Select interface, reading/input and reply languages independently (Chinese, English, Spanish).
4. Grant Accessibility permission in System Settings. Prepare/test the selected Apple language packs; initial downloads require internet access. Optionally enable launch at login.
5. Open a chat and write directly in WhatsApp in your selected input language. Pause typing for 5 seconds to translate. Review and send manually: the assistant never sends messages.
Undo restores the current original draft. It translates again after 5 seconds unless paused. Matching input/reply languages leave drafts unchanged.
More > Check for Updates checks public GitHub releases anonymously and offers Download and Update when a newer version is available. The assistant verifies the download and restarts. Quit and replace the app in Applications to update; preserve its name/path and settings. A new signature may require refreshing Accessibility permission.
The app is not Developer ID signed or notarized. Contact IT if blocked; do not disable macOS security. Translation runs locally; chats are not uploaded. Apple provides language packs, GitHub provides releases. Review important translations. Live reading covers loaded text; import exports for older history. Image/audio contents and other platforms/clients are unsupported.
Native acceptance used Chinese-language WhatsApp 2.26.46.15. English/Spanish WhatsApp envelope parsing is fixture-tested, not yet live-accepted. The assistant UI itself supports all three languages.
Independent project, not affiliated with WhatsApp or Meta.
